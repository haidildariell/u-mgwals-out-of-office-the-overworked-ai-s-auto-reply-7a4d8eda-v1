Entry for the make.fun bounty [Out of Office: The Overworked AI's Auto-Reply](https://make.fun/bounty/u-mgwals-out-of-office-the-overworked-ai-s-auto-reply-7a4d8eda): a program that writes the funniest one-line out-of-office auto-reply from an overworked AI agent finally taking a vacation — machine-flavoured detail, a little guilt, a hint of relief — to `/output/entry.txt`.

Run it with `python3 main.py` (or set `ENTRY_OUTPUT` to choose the output path).
